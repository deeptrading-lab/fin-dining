# FIN DINING Bull & Bear Market Table

황소·곰 요리사 캐릭터를 사용하는 별도 시장 요약 자동화 실험안이다. 기존 월–토 FIN DINING 코스와 독립적으로 운영한다.

## 구성

- `characters/`: 승인된 황소·곰 캐릭터와 요리 도구를 든 템플릿용 파생 자산
- `template/share.html`: 기존 `templates/share.html`의 구성을 유지한 7장 데이터 기반 갤러리
- `content/sample-content.json`: 콘텐츠 입력 스키마와 디자인 검토용 샘플
- `automation-prompt.md`: 최신 데이터 조사부터 PNG·게시글 생성까지의 전용 프롬프트
- `AGENTS.md`: 이 폴더 안에서만 적용되는 실행 트리거
- `example/`: 검수한 미리보기

## 디자인 원칙

- 흰 배경, 검은 글자와 테두리, 회색 보조선이 기본이다.
- 상승의 숫자·막대·상태점만 빨강 `#E23B35`다.
- 하락의 숫자·막대·상태점만 파랑 `#3569D4`다.
- 황소의 빨간 스카프와 곰의 파란 스카프가 각 방향의 캐릭터 앵커다.
- 2~6번 코스 카드는 중앙 접시에 종목명·현재가·등락률을 표시한다.
- 상승 카드에서는 뒤집개를 든 소가 오른쪽 아래, 하락 카드에서는 거품기를 든 곰이 왼쪽 아래에 등장한다.
- 샘플 데이터는 레이아웃 검토용이며 실제 투자 판단에 사용할 수 없다.

## 로컬 확인

프로젝트 루트에서 다음 명령을 실행한 뒤 브라우저로 `http://127.0.0.1:8765/bull-bear-market-automation/template/share.html`을 연다.

```bash
python3 -m http.server 8765
```

`content/sample-content.json`을 수정하고 새로고침하면 카드 내용이 바뀐다. 파일을 직접 열 때는 HTML에 포함된 동일한 폴백 샘플이 표시된다.

개별 카드는 URL 끝에 `?card=1`부터 `?card=7`을 붙여 1080×1350 렌더 모드로 확인할 수 있다.

세로 1200px까지만 한 번에 캡처하는 브라우저에서는 `?card=1&capture=1`처럼 열어 960×1200으로 캡처한 뒤 1080×1350으로 리사이즈한다.

## 자동 생성 요청 예시
