# FIN DINING Bull & Bear Market Table

황소·곰 요리사 캐릭터를 사용하는 별도 시장 요약 자동화다. KRX 정규장 마감 뒤 당일 방향을 판정해 Bull 또는 Bear 게시물 하나를 만들며, 기존 월–토 FIN DINING 코스와 독립적으로 운영한다.

## 구성

- `characters/`: 승인된 황소·곰 캐릭터와 요리 도구를 든 템플릿용 파생 자산
- `design-review/2026-09-08-tableware-cover-v2/template/share.html`: 현재 승인된 7장 데이터 기반 템플릿
- `design-review/2026-09-08-tableware-cover-v2/content/sample-content.json`: 현재 콘텐츠 입력 스키마와 디자인 검토용 샘플
- `template/share.html`, `content/sample-content.json`: 레거시 참고본
- `automation-prompt.md`: 최신 데이터 조사부터 PNG·게시글 생성까지의 전용 프롬프트
- `AGENTS.md`: 이 폴더 안에서만 적용되는 실행 트리거
- `example/`: 검수한 미리보기

## 디자인 원칙

- 확정된 웜 아이보리 배경 `#FBF8F2`, 밝은 종이색 접시·말풍선, 검은 글자와 테두리, 회색 보조선이 기본이다.
- 기본 출력은 웜 아이보리다. `?palette=ivory|blue|sage|blush`는 보관된 비교 시안을 확인할 때만 사용한다. 배경색은 등락 의미를 갖지 않는다.
- 곰은 템플릿의 흰색 채움 레이어로 얼굴·모자·귀·의상·손발을 불투명하게 표시한다. 캐릭터 바깥과 거품기 철사 사이는 배경이 비친다.
- 황소는 콧구멍 없는 U자형 코뚜레 버전을 사용한다. 캐릭터의 투명 여백을 제외한 외곽 기준으로 말풍선 간격을 맞춘다.
- 코스·메뉴: 말풍선 몸체와 캐릭터 외곽 2.6cqw(꼬리 끝 기준 1.15cqw). 커버: 곰과 황소 모두 말풍선 몸체에서 2cqw.
- 상승의 숫자·막대·상태점만 빨강 `#E23B35`다.
- 하락의 숫자·막대·상태점만 파랑 `#3569D4`다.
- 황소의 빨간 스카프와 곰의 파란 스카프가 각 방향의 캐릭터 앵커다.
- 2~6번 코스 카드는 중앙 접시에 종목명·현재가·등락률을 표시한다.
- 상승 카드에서는 뒤집개를 든 소가 오른쪽 아래, 하락 카드에서는 거품기를 든 곰이 왼쪽 아래에 등장한다.
- 샘플 데이터는 레이아웃 검토용이며 실제 투자 판단에 사용할 수 없다.

## 로컬 확인

프로젝트 루트에서 다음 명령을 실행한 뒤 브라우저로 `http://127.0.0.1:8765/bull-bear-market-automation/design-review/2026-09-08-tableware-cover-v2/template/share.html`을 연다.

```bash
python3 -m http.server 8765
```

승인 템플릿 폴더의 `content/sample-content.json`을 수정하고 새로고침하면 카드 내용이 바뀐다. 파일을 직접 열 때는 HTML에 포함된 폴백 샘플이 표시된다.

개별 카드는 URL 끝에 `?card=1`부터 `?card=7`을 붙여 1080×1350 렌더 모드로 확인할 수 있다.

세로 1200px까지만 한 번에 캡처하는 브라우저에서는 `?card=1&capture=1`처럼 열어 960×1200으로 캡처한 뒤 1080×1350으로 리사이즈한다.

## 자동 생성 요청 예시

프로젝트 루트 또는 이 폴더에서 `오늘 게시물 만들어줘`나 `오늘 Bull & Bear 만들어줘`라고 요청한다. KRX 공식 종가가 확정되면 `automation-prompt.md`의 `MARKET PLATE RULE v1.0`이 KOSPI를 1차 앵커로 삼고 보합권에서 시장폭을 확인해 `bull` 또는 `bear` 하나만 생성한다.

## 방향 판정 요약

- KOSPI가 `+0.20%` 이상이면 `bull`, `-0.20%` 이하면 `bear`다.
- KOSPI가 그 사이의 보합권이면 KOSPI·KOSDAQ 보통주 합산 상승 종목 수와 하락 종목 수 중 많은 쪽을 따른다. ETF·ETN·ELW·우선주·스팩·거래정지·보합 종목은 제외한다.
- 시장폭 동률·확인 불가는 KOSDAQ 부호, 그다음 KOSPI 미세 부호로 판정한다.
- 모든 값이 중립이거나 휴장·종가 미확정이면 게시물을 만들지 않는다.
- 수급·뉴스·선물·변동성은 방향을 바꾸지 않고 원인과 강도를 설명하는 데만 사용한다.
- KOSPI와 KOSDAQ 또는 시장폭이 엇갈리면 캡션에 `체감 혼조`, 둘 다 반대면 `지수와 체감 괴리 큼`을 표시하되 선택 방향은 바꾸지 않는다.

## 배경색 비교 시안

`design-review/2026-09-07/palette-comparison.html`에서 황소·곰 카드 4안을 비교하고 각 커버 시안을 열 수 있다.

배경색은 흰색을 약 50% 혼합한 더 연한 2차 시안으로 갱신했다: 아이보리 `#FBF8F2`, 블루 `#F6F9FC`, 세이지 `#F7FAF7`, 블러시 `#FCF7F6`. 기존 시안은 `design-review/2026-09-07/previous-colors/`에 보관한다.

2026-09-07 사용자 확정: 더 연한 2차 시안의 **웜 아이보리 `#FBF8F2`**로 진행한다. 템플릿 기본값과 `example/`의 7장 미리보기에 반영되어 있다.

## 최종 결과 정리

검수 완료 후 당일 `output/YYYY-MM-DD/`에는 선택된 `bull/` 또는 `bear/` 폴더 하나만 남긴다. 그 안에는 카드 PNG 7장과 `caption.md`, `reels-script.md`, `story-copy.md`만 둔다. ZIP은 만들지 않으며 반대 방향 패키지, 미리보기·HTML·데이터·조사 자료·검수 기록·이전 버전은 삭제한다. 필요한 출처와 방향 판정값은 원고에 포함한다. 공용 템플릿과 캐릭터는 보존한다.
