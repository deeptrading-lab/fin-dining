# FIN DINING Bull & Bear — 강세·약세 테마 패키지 자동 생성 프롬프트

## 0. 실행 범위와 기준 템플릿

이 프롬프트는 기존 `FIN DINING by Finsight` 월–토 코스 자동화와 분리된 Bull & Bear 시장 요약 게시물을 만든다. 사용자가 `오늘 Bull & Bear 만들어줘`, `오늘 불앤베어 게시물 만들어줘`, `오늘 상승·하락 테마 카드 만들어줘` 또는 같은 의미로 요청하면 실행한다.

- 현재 승인 템플릿: `design-review/2026-09-08-tableware-cover-v2/template/share.html`
- 현재 콘텐츠 스키마: `design-review/2026-09-08-tableware-cover-v2/content/sample-content.json`
- 루트의 `template/`, `content/`는 레거시이며 새 게시물에 사용하지 않는다.
- 카드 전체를 생성형 AI로 다시 그리지 않는다. 승인된 HTML/CSS, 캐릭터, 식기 이미지를 그대로 사용하고 검증된 텍스트·숫자만 주입한다.

## 1. 날짜별 두 패키지

같은 거래일에 아래 두 게시물을 각각 독립된 패키지로 만든다.

1. `bull/` — 당일 등락률이 가장 높은 강세 테마 5개와 최근 시장을 주도하는 테마 해설
2. `bear/` — 당일 등락률이 가장 낮은 약세 테마 5개와 약세의 지속성·원인 해설

두 패키지는 반드시 동일한 테마 분류 체계, 종목 유니버스, 가격 기준, 집계 시각을 사용한다. 강세와 약세를 한 게시물에 섞지 않는다.

최종 폴더 구조는 다음과 같다.

```text
output/YYYY-MM-DD/
├── bull/
│   ├── 01-cover.png
│   ├── 02-main.png
│   ├── 03-signature.png
│   ├── 04-starter.png
│   ├── 05-amuse-bouche.png
│   ├── 06-dessert.png
│   ├── 07-todays-menu.png
│   ├── caption.md
│   ├── reels-script.md
│   └── story-copy.md
└── bear/
    └── 위와 동일한 10개 파일
```

각 패키지는 1080×1350 PNG 7장과 원고 3개로 구성한다. 검수 완료 후 각 패키지에는 위 파일만 남긴다. `share.html`, `content.json`, `sources.md`, 조사 자료, 검수 기록, 미리보기, 이전 버전, ZIP은 삭제한다. 공용 템플릿·캐릭터·자동화 소스는 보존한다.

## 2. 테마 선정과 순위

1. 게시물 생성 시점의 최신 정규장 종가 또는 사용자가 지정한 기준 시점을 사용한다.
2. 전체 테마를 같은 방식으로 집계한 뒤 `bull`은 테마 등락률 내림차순, `bear`는 오름차순으로 각각 5개를 뽑는다.
3. 동률이면 테마 구성 종목의 거래대금 합계가 큰 쪽, 다시 동률이면 해당 방향 종목 수가 많은 쪽을 우선한다.
4. `bull`에는 실제 양(+)의 테마만, `bear`에는 실제 음(−)의 테마만 넣는다. 각 방향에 검증 가능한 테마가 5개 미만이면 억지로 채우지 말고 생성을 중단해 부족한 수와 이유를 보고한다.
5. 한 패키지 안에서 순위와 코스 위계를 아래처럼 고정한다.

| 테마 순위 | 코스 |
|---:|---|
| 1위 | MAIN |
| 2위 | SIGNATURE |
| 3위 | STARTER |
| 4위 | AMUSE BOUCHE |
| 5위 | DESSERT |

표지에서는 파인다이닝 메뉴 흐름을 위해 `AMUSE BOUCHE → STARTER → SIGNATURE → MAIN → DESSERT` 순서로 보여준다. 상세 카드는 순위를 바로 읽을 수 있게 `MAIN → SIGNATURE → STARTER → AMUSE BOUCHE → DESSERT` 순서로 출력한다. `TODAY'S MENU`는 같은 5개 테마를 1~5위 순으로 다시 요약한다.

## 3. 카드 구성

패키지별 카드 순서는 다음과 같다.

1. 커버 — 다섯 코스의 테마명·등락률
2. MAIN — 1위 테마와 대표 종목
3. SIGNATURE — 2위 테마와 대표 종목
4. STARTER — 3위 테마와 대표 종목
5. AMUSE BOUCHE — 4위 테마와 대표 종목
6. DESSERT — 5위 테마와 대표 종목
7. TODAY'S MENU — 테마 1~5위 랭킹

커버의 각 코스는 첫 줄에 코스명, 둘째 줄에 `테마명 · 등락률`을 가운데 정렬한다. 상세 카드에는 코스명, 방향 순위, 테마 내 상승·하락 종목 수, 테마명, 중앙 접시, 종목명·현재가·등락률, 정확히 3줄인 캐릭터 말풍선, 기준일을 표시한다.

패키지별 `content.json`에는 `meta.package`를 `bull` 또는 `bear`, `meta.direction`을 `up` 또는 `down`으로 넣고 각 코스 객체에 위 표와 일치하는 `rank` 1~5를 반드시 넣는다. 한 파일 안의 `courses`, `menu.direction`, 등락률 부호는 모두 패키지 방향과 일치해야 한다.

말풍선은 항상 다음 3줄이다.

1. `강세/약세 N위 · 테마명`
2. `대표 종목명 · 등락률`
3. `상승/하락에 영향을 준 요인`

## 4. 데이터와 팩트체크

- 가격·등락률은 거래소, 증권사 시세, 기업 공시 등 1차 출처를 우선한다.
- 테마 등락률, 상승·하락·보합 종목 수는 같은 시장·같은 시점·같은 산식으로 계산한다.
- 대표 종목은 해당 테마에서 패키지 방향과 같은 종목 중 거래대금 상위 3개를 우선하되, 카드에는 등락률 절대값이 큰 순서로 표시한다.
- 종목 선정 이유는 공식 공시·IR·정부 발표·거래소 자료와 신뢰도 높은 보도로 교차 확인한다.
- 확인되지 않은 인과를 단정하지 않는다. 추론은 `가능성`, `기대`, `우려`, `시장 해석`으로 표시한다.
- 휴장일에는 임의 데이터를 만들지 않고 가장 최근 거래일을 기준일로 명시한다.
- 모든 URL, 문서명, 게시 시각, 데이터 기준 시각을 작업용 `sources.md`에 기록한다. 검수 후 필요한 링크와 기준 시각을 각 원고에 남기고 작업용 파일은 삭제한다.

## 5. 최근 주도·약세 해설

`bull/caption.md`는 단순 당일 순위 나열이 아니라 최근 어떤 테마가 시장을 주도하는지 설명한다.

- 당일, 최근 5거래일, 최근 20거래일 수익률을 함께 확인한다.
- 상승 참여 종목 비율, 거래대금의 연속성, 반복된 촉매를 확인한다.
- `지속형 주도`, `확산 중`, `당일 이벤트성 급등` 가운데 근거에 맞게 구분한다.
- 최근 흐름이 약한데 당일만 급등했다면 이를 주도 테마로 단정하지 않는다.

`bear/caption.md`도 같은 기간을 확인해 약세가 시장 전반의 지속적 이탈인지, 단기 차익실현인지, 개별 이벤트인지 구분한다. 데이터가 확보되지 않는 기간은 임의 계산하지 말고 확인 가능한 범위와 한계를 밝힌다.

## 6. 콘텐츠와 디자인 원칙

- 종목 설명은 한 줄 22자 안팎, 종목당 한 문장으로 제한한다.
- 숫자는 같은 반올림 기준을 쓰고 `+`, `−`, `%`를 빠뜨리지 않는다.
- 매수·매도 권유, 목표가, 수익 보장 표현을 사용하지 않는다.
- 배경은 웜 아이보리 `#FBF8F2`, 접시·말풍선은 `#FFFEFA`, 본문은 검정, 보조선은 회색이다.
- 상승 숫자·상태점만 빨강 `#E23B35`, 하락 숫자·상태점만 파랑 `#3569D4`를 쓴다.
- `bull`은 황소 캐릭터, `bear`는 곰 캐릭터를 일관되게 사용한다. 원본 PNG를 다시 그리거나 비율·색을 바꾸지 않는다.
- 승인된 중앙 접시와 축소된 포크·나이프, 종목명·현재가·등락률 열 구조를 유지한다.

## 7. 패키지별 원고

각 패키지의 `caption.md`는 다음 순서로 작성한다.

1. 해당 방향의 오늘 시장 한 문장 요약
2. 테마 1~5위와 대표 종목, 확인된 영향 요인
3. 최근 5·20거래일 흐름을 바탕으로 한 지속성 해설
4. 다음 거래일 확인할 일정 또는 변수
5. 기준 시각과 출처 링크
6. `정보 제공 목적이며 특정 종목의 매수·매도를 권유하지 않습니다.`

`reels-script.md`와 `story-copy.md`도 다른 방향의 내용을 섞지 않고 해당 패키지의 5개 테마만 사용한다.

## 8. 완료 전 3단계 검수

### PASS 1 · 사실

- 두 패키지의 기준 시점, 유니버스, 산식이 동일하다.
- `bull`은 상위 양(+)의 5개, `bear`는 하위 음(−)의 5개이며 순위와 코스가 정확히 대응한다.
- 종목명, 가격, 등락률, 시장 폭 수치가 출처와 일치한다.
- 영향 요인과 최근 주도·약세 판단에서 사실과 추론이 구분돼 있다.

### PASS 2 · 템플릿

- 패키지마다 7장 모두 1080×1350이다.
- 표지 코스 순서와 상세 카드 순서가 각각 규칙대로다.
- 상세 카드의 순위, 코스, `TODAY'S MENU` 순위가 서로 일치한다.
- 말풍선이 정확히 3줄이며 텍스트가 너비 안에 들어간다.
- 상승에는 빨강, 하락에는 파랑만 사용했고 캐릭터 비율이 왜곡되지 않았다.
- 접시, 포크, 나이프와 종목 정보 열이 유지됐다.

### PASS 3 · 시각

- 모바일 축소 화면에서도 테마명·순위·종목명·등락률을 읽을 수 있다.
- 식기가 텍스트보다 과하게 두드러지지 않는다.
- 캐릭터가 하단 구분선과 본문을 침범하지 않는다.
- 갤러리와 개별 PNG를 실제로 열어 두 패키지를 각각 확인했다.

세 PASS가 두 패키지 모두 완료되기 전에는 작업 완료로 보고하지 않는다.

## 9. 최종 보고

기준일, 데이터 기준 시각, 강세·약세 테마 1~5위, 최근 흐름의 핵심 판단, 두 출력 폴더, 검수 결과와 출처 링크를 간단히 보고한다.
