# v4.1 화살표 정렬 수정

## 원인

인과 흐름 카드의 화살표 몸통은 시작점과 끝점으로 그렸지만 머리는 별도의 고정 삼각형 좌표로 만들었다. 오른쪽 아래 방향에서는 비슷하게 보였지만 왼쪽 아래 방향에서 머리 중심축과 선의 진행 방향이 어긋났다.

## 수정

- 시작점과 끝점으로 단위 방향 벡터를 계산한다.
- 수직 벡터로 머리 밑변의 좌우 꼭짓점을 계산한다.
- 몸통을 끝점이 아니라 머리 밑변까지만 그린다.
- 외적 오차와 방향 코사인으로 머리 중심축 정렬을 자동 검사한다.
- 정렬 실패 시 렌더 전체를 실패 처리한다.

## 검수 결과

- 화살표 1: 외적 오차 0.0, 방향 코사인 1.0
- 화살표 2: 외적 오차 0.0, 방향 코사인 1.0
- 원본, 전체 미리보기, 390px 모바일 미리보기 육안 검수 통과
