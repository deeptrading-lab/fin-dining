# 금요일 결과 합성 피드백

## 발견한 문제

1. 표지에서 고정 메타데이터 `COURSE 05`와 편집 eyebrow `COURSE 05 · WEEKLY CLOSE`가 반복됐다.
2. 6장 첫 번째 기회 문구의 `회복`이 연한 초록 캡슐 밖으로 내려갔다.
3. 6장의 자주색 캡슐은 텍스트가 없어 미입력 슬롯처럼 보였다.
4. 6장은 문구 길이와 무관하게 2열 고정이라 긴 문구를 수용하지 못했다.
5. 5장 선그래프는 4.65~4.72%의 7bp 변화를 전체 높이로 확대해 실제 변동보다 커 보일 수 있었다.
6. 기존 QA는 렌더 성공과 육안 확인을 기록했지만 텍스트 바운딩 박스가 캡슐 안에 있는지 검증하지 못했다.

## 즉시 반영한 수정

- 표지 eyebrow를 `이번 주 채권의 반전`으로 교체했다.
- 6장의 빈 캡슐을 번호 배지로 교체했다.
- 기회·리스크 텍스트 폭을 먼저 측정하고 2열 또는 2행 구조를 자동 선택하게 했다.
- 차트 설명에 `4.65~4.72%, 변동 범위 7bp`를 명시했다.
- 최종 자동화 프롬프트 5.1과 PASS 3에 재발 방지 규칙을 추가했다.

## 적응형 v4 권고

브랜드 토큰·요일 색상·폰트·안전 여백은 고정하되 카드 수, 컴포지션, 차트 유형, 열 수, 카드 높이, 히어로 배치는 콘텐츠에 따라 선택하는 것이 적합하다. 텍스트와 숫자는 계속 코드로 렌더링하고, 생성형 AI는 글자가 없는 히어로 자산에만 사용한다.
