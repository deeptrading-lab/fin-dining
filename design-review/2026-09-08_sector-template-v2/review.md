# 주도 섹터 코스 템플릿 v2 검수 기록

기준 게시물은 2026-09-07 KOSPI 업종 종가 데이터다. 1080×1350 원본과 390px 축소 미리보기를 함께 확인했다.

## 디자인 확정안

- 포크·나이프: 갈색 손잡이 일러스트를 폴리시드 실버 커트러리 컷아웃으로 교체
- 접시: 단순 타원 도형 대신 브러시드 실버 차저, 비드 림, 백자 플레이트가 겹친 실제 상차림 자산 사용
- 표지: 동일 크기 5행 목록을 `전채 2열 → 시그니처 → 메인 카르투슈 → 디저트`의 테이스팅 메뉴로 재구성
- 메인: 보조 코스보다 업종명은 약 1.5배, 상승률은 약 1.4배 크게 표시하고 독립 면을 부여
- 텍스트·수치·로고는 모두 Pillow 합성 유지. 생성 자산에는 글자·숫자·로고가 없다.

## 콘텐츠 검수 요청자 모드 · 1차

- 발견: 표지의 다섯 상승률이 모두 같은 빨강이라 MAIN과 보조 코스가 경쟁했다.
- 개선: 보조 코스 상승률은 은회색으로 낮추고 MAIN 업종명·상승률만 강한 대비를 유지했다.
- 결과: 표지를 축소해도 첫 시선이 `기계·장비 +6.60%`에 고정된다.

## 콘텐츠 검수 요청자 모드 · 2차

- 발견: 상세 접시의 가운데 숫자가 종가인지 다른 지표인지 열만 보고 즉시 알기 어려웠다.
- 개선: 접시 웰 상단에 `종목 / 종가(원) / 등락률` 열 머리를 추가했다.
- 결과: 숫자 의미가 명확해지고 카드 본문과 말풍선 사이의 정보 중복도 늘지 않았다.

## 콘텐츠 검수 요청자 모드 · 3차

- 발견: 마지막 10개 업종 보드가 평면 목록으로 끝나 표지의 MAIN 서사가 회수되지 않았다.
- 개선: 1위 행에 실버 하이라이트 면을 깔고 순번만 요일 포인트 컬러로 표시했다.
- 결과: `표지 MAIN → 상세 MAIN 접시 → 마지막 1위`의 읽기 흐름이 닫힌다.

## 최종 판정

- PASS 1 사실·원고: 업종 등락률과 종목 종가·등락률을 2026-09-07 기준으로 교차검증했고, 업종지수와 선별 종목을 구분했다.
- PASS 2 템플릿·기술: 7장 모두 1080×1350 RGB PNG이며, 월요일 accent와 선언 폰트를 사용했다.
- PASS 3 시각·폰트: 원본·390px 축소에서 잘림, 겹침, 깨진 글자, 의미 없는 장식 슬롯이 없음을 확인했다.
